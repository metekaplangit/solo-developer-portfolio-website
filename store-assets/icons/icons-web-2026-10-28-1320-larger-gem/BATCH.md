# icons-web-2026-10-28-1320-larger-gem

The studio's gem logo, unchanged in shape and colour, grown from 55% to 79% of its tile so it reads at tab and home-screen sizes, plus a link preview drawn at the size previews are actually shown. The first batch in this folder; the previous mark lived only in `public/`.

No platform record exists in the project's root instruction file; the site is a website, so this batch is for the web.

## How it was made

Drawn by hand as vector, from the 2026-07 mark in `public/favicon.svg`. No generated image ships in this batch, so no model's terms attach to it; the studio owns it as it owned the mark before.

The run did generate probe sheets on fal while the owner chose a direction. None of them was picked, and they stay in scratch:
