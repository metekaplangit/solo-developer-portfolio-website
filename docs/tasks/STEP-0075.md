# Task Card — STEP-0075

- **ID:** STEP-0075
- **Type:** fix (the void above the gallery)
- **One outcome:** The gap between a product page's header block and its gallery belongs to the page's own rhythm instead of standing outside it.
- **Feedback:** `2026-08-03-product-page-empty-space` — the owner boxed an empty band on `/apps/magic-notes/` and asked for the space to be reduced on the product pages, not only that one.
- **Why now:** it is the largest single gap on the two pages a store reviewer and a first-time visitor both land on, and the owner reported it against the live site.
- **What it actually was, measured rather than judged:** **144px**, against 80px below the gallery and 8–24px inside the header block. It was two rhythms stacked: the band around the gallery contributed `--band-y-loose` (120px at 1440px) and the gallery contributed `padding-block: var(--space-6)` (24px) of its own. Neither value was wrong; owning the same gap twice was.
- **Approach:** two changes, both removing a duplicate rather than inventing a number. The gallery drops its own `padding-block` — the band around it already owns that space (CHECKLIST W2). The band drops `band-loose` for plain `band`: loose means "a new argument starts here", and a gallery of the product the header just named is not a new argument.
- **Avoid:** picking a pixel value to make the gap look right. A measurement that comes from neither the spacing scale nor the band rhythm is a rule nobody can follow afterwards (CHECKLIST L4).
- **Acceptance criteria:** (1) the gap above the gallery is smaller than it was and no larger than the page's other rhythm steps. (2) It is balanced against the gap below the gallery rather than double it. (3) Every value still comes from a token. (4) No other gap on the page moves.
- **Non-goals:** the two 120px `band-loose` gaps lower down (`what it does` → prose, prose → get band). Those are the declared loose step, used consistently, and each marks a genuine change of subject — a rhythm, not a void. Named here so the owner can say otherwise.
- **Files:** `src/components/ScreenshotShowcase.astro`, `src/pages/apps/[slug].astro`, `docs/STATUS.md`, `docs/ROADMAP.md`, `docs/CHECKPOINTS.md`, `docs/CHANGELOG.md`.
- **Evidence method:** the built pages rendered in a headless browser and the gaps measured, before and after, on both product pages.
- **Proof classification:** machine-verifiable measurement, plus a rendered comparison.
- **Required checks:** `npm run build`; `npm run check`; `npm test`; `npm run test:dist`; `python3 scripts/validate-governance.py`.
- **Rollback/containment:** `git revert -m 1`. Two declarations; reverting restores the previous spacing exactly.
- **Issue links:** none. Owner feedback, 2026-08-03.
- **Evidence after completion:** Gates: build exit 0 (10 pages), check exit 0 with 0/0/0, 111/111 unit tests, 14/14 dist tests, validator 44/44.
