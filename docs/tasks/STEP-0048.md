# Task Card — STEP-0048

- **ID:** STEP-0048
- **Type:** feature (UI — reading routes + the display ramp)
- **One outcome:** The five reading routes join the Spectrum system, every page title on the site comes from one three-step display ramp instead of four different sizes, and the in-content link underline finally applies on About and Support.
- **Why now:** Fifth card of six. These are the trust pages — a visitor checking whether the studio is real lands here — and they were the last routes still carrying their own heading sizes. The ramp is defined here rather than in STEP-0049 so that the closing card is pure measurement rather than measurement plus design.
- **Acceptance criteria:** (1) Privacy index, privacy detail, support, about and 404 render on the Spectrum system. (2) One display ramp, three steps, used by every route. (3) The underline applies for real on About and Support — proved by computed style, not by eye. (4) Policy heading order unchanged (`h1 → h2 → h3`). (5) 0 horizontal overflow across the full width matrix.
- **The drift this fixes:** the eight routes carried **four different `h1` sizes** — a flat `--text-3xl` (2.75rem) on About, Support and 404; `clamp(1.75rem, 7vw, 2.75rem)` on policies; `clamp(2.5rem, 7vw, 5.5rem)` on the catalog; `clamp(2.75rem, 8.5vw, 7rem)` on home. The same level of heading changed size depending on which page you were on. Now: `--display-1` home hero (one per site), `--display-2` page mastheads (`.page-title`), `--display-3` a product's name wherever a product leads a surface.
- **Absorbs:** 2026-07-18 health-check **follow-up #3** — the animated in-content underline targeted `.about`/`.support`, which no element carried, so the rules were dead and were removed as dead code without the treatment ever being applied. It now targets `.elsewhere a` and `.products a`, which the markup really has.
- **Explicitly not in scope:** health-check **follow-up #2** — `PolicyArticle.astro` still holds four hardcoded legal sections that the content schema should own. It stays queued. Folding a content-ownership fix into a visual card would hide it.
