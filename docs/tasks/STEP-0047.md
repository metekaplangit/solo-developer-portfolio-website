# Task Card — STEP-0047

- **ID:** STEP-0047
- **Type:** feature (UI — `/apps/` and `/apps/<slug>/`)
- **One outcome:** The catalog becomes one full-width band per product, each in that product's own colour, built from a single shared component that the home page also uses; and a product's own page speaks entirely in that product's voice.
- **Why now:** Fourth card of six. With the home page converted, these are the two routes a visitor reaches next, and the catalog's lead-row was a second copy of the home spotlight — the duplication the 2026-07-18 system health check named as follow-up #1.
- **Acceptance criteria:** (1) One `ProductBand.astro` serves the home page and the catalog; the duplicated lead-row is gone. (2) Each product paints its own band from its own `hue`. (3) The screenshot gallery keeps scroll-snap, arrows, dots, the live counter, keyboard control and the `<details>` transcript. (4) 0 horizontal overflow across the width matrix on both routes. (5) Heading order intact.
- **Design decision — a product's own page IS that product's band, in full.** Rather than teaching each component about hues, the page remaps four accent tokens once (`--accent`, `--accent-hover`, `--accent-soft`, `--accent-contrast`, `--accent-glow` → the hue set) on a single wrapper. The download button, the badges, the gallery controls and the focus ring all pick up the product's colour with no component knowing that hues exist. Contrast holds: hue on stage 8.96:1, hue-button label 8.53:1.
- **Scope call — the detail page keeps its section structure.** It adopts the identity (product voice, poster-scale name) but its gallery / fit / features / prose / get sections are not rebuilt into full-bleed bands. Those are working, tested surfaces — the gallery in particular carries hard-won keyboard, snap and transcript behaviour — and harmony did not require restructuring them. Any residual drift between them and the banded routes is STEP-0049's job, which is the card that can measure it.
- **Did not reintroduce:** the icon-panel/card "Format B" treatment for product descriptions, rejected live by the owner. Descriptions stay prose.
- **Non-goals:** the reading routes (STEP-0048); cross-route alignment (STEP-0049); the gallery's internal markup.
- **Files:** `src/components/ProductBand.astro` (new), `src/pages/apps/index.astro`, `src/pages/apps/[slug].astro`, `src/pages/index.astro` (now consumes the shared band).
