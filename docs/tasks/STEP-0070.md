# Task Card — STEP-0070

- **ID:** STEP-0070
- **Type:** content (the two Magic Notes pages stop being placeholders)
- **One outcome:** `/apps/magic-notes/` and `/privacy/magic-notes/` carry real imagery and a policy read against the shipped app, so a store reviewer opening either URL sees a finished page rather than a stub.
- **Feedback:** Owner instruction, 2026-08-03: the product is being published tonight and may be reviewed; the pages created as placeholders on 2026-08-02 must be filled for real.
- **Why now:** The shipped Magic Notes build hard-codes five studio URLs (`NotebookSettingsView.swift:703-708`), two of which — the marketing URL and the privacy URL — are also the ones App Store Connect is given. STEP-0069 made them resolve; it deliberately left them thin, because no icon, no screenshots and no source-level privacy review existed yet. All three now do. A reviewer following a link baked into a submitted build is the one visitor who cannot be asked to come back later.
- **Prior art:** none sought. Sole Focus already establishes this project's pattern for a product page with imagery, and the Magic Notes project supplies every fact. No external source knows either schema.
- **Avoid:** inventing anything. Every claim traces to the Magic Notes repository — its source, `docs/SECURITY.md`, and the owner-approved copy pack of 2026-08-03. The FAQ added here restates claims already made further up the same page; it introduces no capability.
- **Avoid:** a price, a store link, or a release date. Still unverified: the app has no purchase code anywhere in its source, no listing exists, and the distribution route is unsettled. `status: in-development` and an empty `storeLinks` stay, so the page renders "Not yet available" rather than a download that would 404.
- **Avoid:** a `makerNote`. Schema requires the maker's explicit approval of that exact copy (STEP-0035); it has not been given for this product.
- **Approach:** content and assets only — no component, page, style or schema change. Six captures into `src/assets/magic-notes/screenshots/`, the shipped icon into `public/media/magic-notes/`, and the two Markdown files updated to reference them.
- **Design decision — the imagery is the app's own.** The six frames are the owner's real captures of the running application (`store-assets/screenshots/screenshots/`, 2026-08-03), and the icon is the shipped mark from the icon batch of 2026-08-02. Nothing was generated, mocked up or imitated. Their window chrome reads `v0.309.0` — they predate the version bump — and no claim on the page depends on the number shown, so they ship as taken.
- **Design decision — `reviewStatus: reviewed`, not `published`.** The policy has now been read against the Magic Notes **source**, not its documentation: no networking API is referenced anywhere in the application, no analytics or advertising SDK is linked, `spotlightIndexingEnabled` defaults to false, and the four `AppIntent` types are the only system surface. `reviewed` is what that evidence supports; `published` would additionally assert a legal review that has not happened.
- **Design decision — the deletion route names the real folder.** Apple 5.1.1(i) wants a user to be able to erase everything. Magic Notes has no in-app "erase all" — `Restore Defaults` resets preferences only — so the honest instruction is the storage directory, `~/Library/Application Support/IntelligentWorkingNotebook` (`NotebookStore.swift:387`, deliberately still the pre-rename name). Sole Focus's policy can name an in-app route because Sole Focus has one.
- **Design decision — the page keeps its "In development" badge.** The status vocabulary has no value meaning "finished and awaiting release", and `released` without a store link would render a badge the page cannot honour. The badge stays true, and the page's own closing line carries the nuance.
- **Acceptance criteria:** (1) six screenshots and an icon render on the product page, each with alt text. (2) The policy is no longer marked draft, and states a concrete deletion route. (3) No price, store link or release date is claimed. (4) The submitted privacy URL is unchanged. (5) Every referenced image exists in the built output and decodes.
- **Non-goals:** the Magic Notes home-page band; any change to Sole Focus; the trademark, price, category and sandbox decisions, which are the owner's alone and none of which this touches.
- **Files:** `src/content/products/magic-notes.md`, `src/content/policies/magic-notes.md`, `src/content/products.content.test.ts`, `src/assets/magic-notes/screenshots/*` (new), `public/media/magic-notes/icon.svg` (new), `docs/STATUS.md`, `docs/ROADMAP.md`, `docs/CHECKPOINTS.md`, `docs/CHANGELOG.md`.
- **Evidence method:** full build, the built `dist/` read directly, and the built pages driven in a headless browser — gallery clicked slide by slide, every image checked for real decoded pixels and an alt attribute.
- **Proof classification:** machine-verifiable.
