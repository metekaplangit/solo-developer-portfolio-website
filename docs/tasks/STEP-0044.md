# Task Card — STEP-0044

- **ID:** STEP-0044
- **Type:** feature (content model — per-product identity colour)
- **One outcome:** A product can declare its own identity hue in its content file, and one helper resolves it (or a documented neutral fallback), so the Spectrum bands that follow are painted from content rather than from a colour hardcoded in a page.
- **Why now:** Owner selected design option **E ("Spectrum")** from the 2026-07-31 mockup run — a whole-site makeover whose thesis is that colour comes from the product, not the site. Plumbing the value before any band consumes it keeps `#ff9245` out of `index.astro`. First card of six (STEP-0044..0049).
- **Acceptance criteria:** (1) `hue` is an optional, validated six-digit hex on the product schema. (2) An invalid hue fails the build like every other schema violation. (3) `productHue(product)` returns the authored hue or `NEUTRAL_HUE`. (4) Sole Focus declares `#ff9245`. (5) **No visual change on any route** — nothing consumes the field yet.
- **Design decision — why six-digit hex only:** the value is interpolated straight into a CSS custom property, so shorthand (`#fff`), named colours and functional syntax are rejected at build time rather than normalised at runtime. One authored form, one rendered form.
- **Design decision — why the fallback is near-white, not a second accent:** an unclaimed band should read as studio chrome. A second chromatic default would quietly reintroduce the site-wide accent that option E exists to remove.
- **Non-goals:** consuming the hue anywhere (STEP-0046 onward); a derived `--hue-deep` authored by hand (it is computed with `color-mix`); a light-mode variant.
- **Files:** `src/content/schema.ts`, `src/lib/products.ts`, `src/content/products/sole-focus.md`, `src/content/schema.test.ts`, `src/lib/products.test.ts`.
- **Evidence method:** automated test.
- **Proof classification:** machine-verifiable.
- **Required checks:** `npm run build`; `npm run check`; `npm test`; validator.
- **Issue links:** Owner selection of mockup option E, 2026-07-31. Precedes STEP-0045.
- **Rollback/containment:** the field is optional and unconsumed; `git revert -m 1` on the merge removes it with nothing else affected.
