## What the privacy page says, so the game must keep it true

The policy was written from the game's source on 2026-09-22:

- The game collects nothing and has no account.
- It has no analytics, no advertising, no purchases and no tracking. It plays without the internet.
- Stored only on the iPhone: game progress, settings, and the note from the last crash.
- The crash note reaches the studio only if the player emails it.
- The game is made for a general audience and is not directed at children. Keep the App Store age rating answers in line with that, and do not put the game in the Kids category.

**If a release changes any of this, the website's privacy page must change before that release ships.** That applies above all to AdMob ads, which the owner's notes plan. In that case, tell the owner. The page is edited in the website project, never from the game's project. Ads would also mean updating the iOS privacy manifest (`ios/App/App/PrivacyInfo.xcprivacy`), adding a tracking prompt if personalised ads are used, and rewriting the game's own "Nothing about you is collected" text. Apple compares those against the privacy page.

## When ads and purchases are added

The owner's plan, decided on 2026-09-22. The first release ships with no ad or purchase code at all, not even switched off, because Apple rejects hidden or dormant features (rule 2.3.1). Then, in 1 update:

1. Ask the owner to update the website's privacy page first, so it is live before review.
2. Purchases through Apple's StoreKit only. Apple collects that data, so there is almost nothing to declare.
3. AdMob ads without tracking: no tracking prompt and no advertising ID. The App Store privacy answers still have to list what the Google ads code collects (see Google's "App store data disclosure" page for AdMob on iOS).
4. Google's consent pop-up (the UMP SDK) for players in Europe, the UK and Switzerland.
5. Update the iOS privacy manifest and the game's own privacy text, change the privacy answers in App Store Connect, and describe the new ads and purchases precisely in the review notes.
