Breaking changes read from primary sources and judged against this code:

- **Vitest 5** — `clearMocks` now defaults true, `test.sequential` removed,
  `vi.mock`/`vi.hoisted` now throw outside the top level. **Reaches nothing
  here**: `grep` over `src/` and `tests/` finds no mock, no spy and no
  `.sequential`. Needs Vite >= 6.4.0 and Node >= 22.12.0; Astro already brings
  Vite 8.1.3 and the runtime is Node 24.16.0.
  ([vitest.dev/blog/vitest-5](https://vitest.dev/blog/vitest-5.html),
  [migration guide](https://vitest.dev/guide/migration/))
- **puppeteer-core 25** — ESM-only, min Node 22, `executablePath` and
  `defaultArgs` now return promises. **Reaches nothing here**: the project is
  `"type": "module"` throughout, and no call site invokes `executablePath()` —
  all three call sites pass a path in as an option.
  ([puppeteer changelog](https://github.com/puppeteer/puppeteer/blob/main/packages/puppeteer-core/CHANGELOG.md))
- **TypeScript 6** — `moduleResolution: classic` removed, `esModuleInterop`
  and `allowSyntheticDefaultImports` can no longer be false, ES3/ES5 targets
  deprecated. **Reaches nothing here**: `tsconfig.json` extends
  `astro/tsconfigs/strict` and sets only `strictNullChecks`.
  ([TypeScript 6.0 release notes](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-6-0.html))
- **TypeScript 7** — excluded, see the table above. Proven by running, not by
  reading the peer range.
