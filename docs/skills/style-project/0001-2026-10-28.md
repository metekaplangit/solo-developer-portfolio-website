# Style Project 0001

## The product

- **What it is:** MetKap Studio's public site — a static Astro site presenting 3 shipped products (Magic Notes, Sole Focus, Waypost Words), their privacy pages and a support route. For the indie-Mac-app audience. Web only, English only. The root instruction file has no platform record; the build targets the web.
- **Design language:** `DESIGN.md` at the root ("Spectrum"). Used as the boundary. The code wins where they disagree:
  - `DESIGN.md` front matter gives radii 10/18/24, its prose says 20/14/8; the code is 10/18/24.
  - The `:focus-visible` comment in `global.css` calls `--radius-sm` 8px; it is 10px.
- **Values as they really are** (all in `src/styles/global.css` `:root`; components read the tokens — only 6 colour literals sit outside it):
  - Stage `#08090c`, band `#0c0d11`, surfaces `#121419` / `#171a21` / hover `#1c2029`.
  - Text `#f2f3f6`, strong `#fff`, muted `#a2a7b3`, faint `#8b909c`. Chrome white; one `--hue` per product band (`#ff9245`, `#B2BBC5`, `#C6B4E8`); `--hue-contrast` fixed `#1c0d02`.
  - Hairlines `rgba(255,255,255,.09)` / `.18`. Shadows `--shadow-sm/md/lg`, all falling downward.
  - Radii 10 / 18 / 24 / pill; brand mark 7px.
  - Type: system SF stack, sizes 13/15/17/20/24/32/40/60/68/112 (10), weights 400/600/650/700, plus weights, line heights and letter-spacing typed per component.
  - Blur: header 16px + saturate, gallery glass 8px.
- **Modes:** dark only (`color-scheme: dark`). No `prefers-contrast` rule anywhere in `src/` (0 matches). No light mode — not added here; that would be `mockup-designs`.
- **Way in:** static HTML, no launch screen; `meta theme-color #08090c`; the browser restores scroll on reopen.
- **Feeling:** quiet, exacting, near-black stage, poster-scale type, colour lent by each product. Family: Apple-native dark — SF, tonal surfaces, pill controls.
  - Carried most fully by: home (hero type + the Magic Notes band), the Sole Focus page (hue band, gallery), Waypost Words page (lavender voice, phone frames), Support (cards + tiles).

### 1 — Icon shape

- **Brief.** Weak: icons cut by fixed px radii, 25 / 37.5 / 42.9% by size. Premium: one proportion at every size, matching the icons' own masks. References: apps.apple.com rounds icons with `border-radius: 23%`; Apple's mask on an 824 tile is ~22.5%. Keep: the brand mark's own rule, already written in `Nav.astro` — an icon is a mask, not a UI surface.
- **Made ours.** apps.apple.com uses 23% on its store tiles; Rogue Amoeba ships pre-shaped PNGs; Raycast uses px. Here it is one token beside the radius scale, reaching the brand mark too, and the tile radius follows from it. It is not the look of any of the owner's apps.
- **Research disagreement.** 22.37% (squircle.js, uncited), 22.5% (Apple forum), 23% (apps.apple.com). The spread is under 0.4px at 56px; 22.37% kept.
- **`corner-shape: squircle`** not used: Chrome 139+ only, not in Safari, which most Mac visitors use. The same icon would differ by browser.
- **Rounds.** 1 round. The icons' designed rounded squares returned at once; tile nesting moved from 16px off to 2.7px off. No second round was needed.
- **After readings.** Icon corners 6.3 / 10.7 / 12.5px at 28 / 48 / 56px — 22.37% each. `a.tile` 24 round a 10.7 icon at 16 inset: off 2.7 (was 16).

### 2 — Depth: one light, one lift

- **Brief.** Weak: surfaces lit from below while shadows fall from above; mixed separation cues; black shadows invisible on near-black. Premium: one light direction, depth read from tone plus a lit top edge in the dark, one cue per surface. References: Raycast's most-used shadow is `inset 0 1px #ffffff1a`; Apple's dark mode lifts by brighter "elevated" backgrounds; Atlassian pairs lighter raised surfaces with a shadow. Keep: the Single-Cue Rule, the near-black stage.
- **Made ours.** Raycast sets the highlight on translucent fills with a hairline. Linear leans on flat fills and borders. Here it is the site's own surface gradient turned to fall from the top, with the edge folded into one 3-step `--lift` scale. No hairline is added to any surface.
- **Rounds.**
  - Round 1: edge 7%. The fit cells became lit cards; the support card edges were faint.
  - Round 2: edge 10% (Raycast's measured value), hover 14%. Edges read on every card. Kept.
- **After readings.**
  - Cards, tiles, fit cells and panels carry `inset 0 1px 0 rgba(255,255,255,.1)`.
  - Fit cells no longer carry a border. Icons sit on `--shadow-sm`, not the panel's `--shadow-md`.
  - Lowest text contrast is 5.60:1 (was 5.71).
  - Image frames (gallery frame, band shots) still carry ring + shadow — images, not surfaces; left alone.

### 3 — Type roles

- **Brief.** Weak: 4 weights, 13 line heights and 14 letter-spacings typed per component — 46 combinations for 10 sizes. Premium: few weights, one leading per role, tracking as a function of size. References:
  - Apple's product pages use only 400 and 600.
  - Linear tightens to -0.022em from 32px.
  - Cloud Four's single clamp formula (2025-11-20).
  - Keep: the SF system stack, every size, the poster-tight hero.
- **Made ours.** Apple's web tracking runs about +0.011em at 21px and -0.015em at 80px. Linear uses 4 weights. Here: 3 weights (700 for display only), and one `--track-optical` clamp of the site's own (0 at body size, -0.04em from 40px). No size changed.
- **Research disagreement.** Apple's HIG SF table goes *positive* at 24–68pt. Apple's own web pages and Linear tighten large type instead. The web practice was followed: this is web-rendered display type, and the site already tightened.
- **Rounds.**
  - Round 1: display leading 1.0 loosened the 2-line hero and lost its poster lock.
  - Round 2: 0.96. Kept.
  - The change is consistency felt across pages, not in one glance — **under the 2-second bar.**
- **After readings.**
  - Weights 400/600/700 (was 4).
  - Line heights 0.96 / 1.12 / 1.2 (buttons) / 1.35 / 1.6, plus 1 stray `1` (was 13).
  - Letter-spacings 7, all from 2 tokens (was 14). Combinations 30 (was 46). Lowest contrast 5.71:1, unchanged.

### 4 — Increased contrast

- **Brief.** Weak: nothing changes when a visitor turns on macOS "Increase contrast". Premium: every custom colour has a stronger version, translucency goes solid, and surfaces get an edge. References:
  - apps.apple.com: secondary text 55→70% white, tertiary 25→50%, lines 10→30%, blur off.
  - GitHub Primer's high-contrast borders and muted text are `#b7bdc8`.
  - Apple's colour guidance: a "significantly higher" contrast version of every custom colour.
  - Keep: the near-black stage, the hues.
- **Made ours.** Primer ships a separate theme that users pick by hand. Here the system setting drives it, through token values plus 3 targeted rules. It is the default site with its quiet parts turned up, not another theme.
- **Rounds.**
  - Round 1: the panels kept their old shadow, because the block sat above the panel rule in the same file.
  - Round 2: the block moved last. Every panel now carries the edge. Kept.
- **After readings.**
  - Under `prefers-contrast: more`: hairlines 32% / 56% (were 9% / 18%), muted `#d0d3da`, faint `#babec8`, text `#fff`.
  - 9 surface kinds ringed. Header and gallery glass are solid; link underlines are full strength.
  - Lowest contrast in that mode is 5.86:1, on the hue chip.
  - Default mode: colour readings identical to before.

### 5 — Palette: even ramp, hue-drawn label

- **Brief.** Weak: the band step (ΔE 0.0199) is the smallest of the ramp, the steps are uneven, and every product's button label is Sole Focus brown. Premium: even perceptual steps and a label drawn from each product's hue. References: Radix dark grays step L .03–.04; Linear .139/.172/.195/.217; relative colour `oklch(from …)` has 88% support (caniuse, 2026-09). Keep: the `#08090c` stage, the one blue-grey tint.
- **Made ours.** Radix and Linear publish grey ladders. Here the ladder is the site's own 268° blue-grey, and the label ink is derived per product. No source tested a hue-tinted ink — this is the run's own idea, flagged as such.
- **Rounds.**
  - Round 1: steps .03, ink L .20 C×0.4. Mean pixel change under 1.3/255 — not visible.
  - Round 2: steps .035, ink L .22 C×0.6. Kept; still quiet.
  - A 3rd round would lift surfaces enough to fight the near-black stage, so it stopped — **under the 2-second bar.**
- **After readings.**
  - Ramp L .140 / .174 / .209 / .245 / .280 — `#08090c` `#0f1015` `#16181d` `#1e2027` `#262931`.
  - Inks: Sole Focus `#390400`, Waypost Words `#1e152c`, Magic Notes `#171b1f`.
  - Lowest contrast 5.55:1. The band near-duplicate is gone.
