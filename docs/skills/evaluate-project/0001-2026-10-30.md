## Research (this run)

- TypeScript 7.0 (July 2026) is the Go compiler; Astro's `astro check` needs
  TypeScript 6 until a stable API ships, expected in 7.1
  ([InfoQ](https://infoq.com/news/2026/08/typescript-7-released/),
  [dev.to](https://dev.to/morellodev/typescript-7-is-here-the-compiler-got-rewritten-in-go-53cn)).
  `npm outdated` lists 7.0.2 as latest; followed the research — staying on 6 is right.
- Astro 7.1 added `style-src-attr` kinds; the project already uses them
  ([releases.sh](https://releases.sh/astro/astro-changelog.md)).
- A meta-tag CSP cannot carry `frame-ancestors` or report-only; GitHub Pages
  cannot set headers ([dev.to](https://dev.to/jacobandrewsky/how-to-set-content-security-policy-with-a-meta-tag-5gfm),
  [hotosm issue](https://github.com/hotosm/tech/issues/127)). Already recorded in
  `astro.config.mjs`; Workers and Pages are ruled out by the project's
  zero-cost rule.
- ISO/IEC 25010:2023 renamed usability to "interaction capability"
  ([Sonar](https://www.sonarsource.com/resources/library/iso-iec-25010-explained/)).
  UI & UX plus Accessibility already cover it — nothing added.
