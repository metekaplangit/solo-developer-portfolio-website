## What the run got wrong

- **Too many paid sheets, and the wrong medium.** The run drew 8 paid sheets in brighter colours and invented metaphors before reaching the answer the owner wanted: their own mark, kept. The 2 vector rounds that found it cost nothing and took minutes. When an existing mark is close to right, draw its variations as vector before paying a generator.
- **Answers that never arrived.** The pick question came back 8 times as "the user sent a message instead", with no message attached. Each time the run stopped and asked again in chat.

## Anything the provider file got wrong

- **Nano Banana Pro price:** fal.md says $0.15 an image "any size". At 4K the published price is 2 times that, $0.30.
- **GPT Image 2.5 Flare:** the file still marks it "not measured yet" for some tiers. Its pricing call this run answered "unit_price 1, unit: units", the same after-the-fact metering the file describes for GPT Image 2, so a price before the call is still unknowable.
- **Off-grid tiles:** at 2880 x 2880 the model places tiles off an even 720 px grid. A view cut on that grid sliced the bottom rows; cutting on each tile's measured edges fixed it.
- **The shape check tool** (probe-spread, not the provider file): when every tile is the same dark rounded square, it reports "every cell is the same shape" even when the marks inside differ, because it reads the tile's outline. On those sheets the spread was judged by eye.
