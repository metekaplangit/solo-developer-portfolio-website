## Research (read this run, 2026-10-28)

Guidance: NN/g "Cards Component" (2016-11-06) — plain lists beat cards for scanning similar items. 2. **Closing block** — rogueamoeba.com/audiohijack ("Get" block + version + date, sibling apps with icons), halide.cam ("Get Halide Now" + sibling app promo), culturedcode.com/things (per-platform cards). Guidance: Apple marketing guidelines (undated, © 2026); WCAG 2.2 target size (updated 2026-05-11). Craft: Evil Martians (2025-07-08) — one standalone closing block; Eleken footer UX (updated 2026-05-28).
3. **Privacy index** — apple.com/legal/privacy/data, mozilla.org/privacy, policies.google.com product privacy: all text-only; no studio found with icon + date. Guidance: App Store Review Guidelines 5.1.1(i); CNIL summarising tables. Craft: none verified this run (marked weak).
4. **Support product chooser** — rogueamoeba.com/support (icon + name tiles), help.panic.com (section per product with icon), bjango.com/help (name + tagline cards). Guidance: Review Guidelines 1.5; WCAG target size. Craft: LogRocket help-desk UX (2025-09-04); Userpilot help-centre designs (updated 2026-08-20).
5. **FAQ** — sindresorhus.com/apps/faq (63 native `<details>`), flighty.com/pricing (open list), raycast.com/pricing (accordion, inferred). Guidance: W3C APG disclosure (© 2026); MDN `<details>` (2026-10-16); NN/g accordions (2023-07-30) — show all when people need most of it; NN/g FAQs (2014-12-21). Craft: Chrome `::details-content` (2024-11-06); modern-css.com details animation (2026-04-30).

## The 5

### 1. What it does — product pages · new

- **Bar:** a visitor sees a wall of 12 identical grey boxes — the exact thing `DESIGN.md` names as the anti-reference.
- **Brief:** weak — boxed, muted, uniform; premium — a scannable spec list; refs — Things' small-feature list, NN/g lists-over-cards; keep — hairlines, home page's hue-numbered index.
- **Made ours:** rivals use icon rows or titled sections; this one is a 2-rail ruled list with hue index numbers, the layout of the site's own policy rows. Shared core: listing features.
- **Rounds:** 1 built; 2 `text-wrap: balance` (item 07 broke "chosen / by you rather / than by your region"); 3 non-breaking hyphens ("exchange- / rate", "library- / wide").
- **After (1440):** band 1232×496 (was 442); claim text 17px/400 `#f2f3f6` (was 15px `#a2a7b3`); rows 117.5px, 1px hairline, 3 columns × 4 rows, heading in a 240px rail. (390): 1209px tall (was 1306).
- **2-second test:** passes — boxes gone, numbered list.

### 2. Get panel, meta and More apps — product pages · new

- **Bar:** the page ends on a small grey button, two loose rows of facts, and a sibling app as a bare word.
- **Brief:** weak — split blocks, no icon; premium — one closing surface + recognisable siblings; refs — Rogue Amoeba "Get" block, Halide closing; keep — panel-accent, hue Download button.
- **Made ours:** rivals stack badge, version and a site directory; here the facts become the panel's own footer strip, and siblings use the shared product tile. Shared core: a download action.
- **Rounds:** 1 built; 2 none needed; 3 fluid title so "Get Magic Notes" stays 1 line at 390.
- **After (1440):** panel 1232×239 (was 147, with meta 40px outside it); meta strip 91px inside, `rgba(0,0,0,.18)`, hairline top; title 32px (was 24px); 56px icon; Download is the header's own `DownloadButton` (44px); tile 80px.
- **2-second test:** passes.

### 3. App & game privacy policies — privacy index · new

- **Bar:** 2+1 grid with a hole, no icons, dates in a code font — on the page store reviewers open.
- **Brief:** weak — text cards; premium — icon-led full row; refs — Apple/Mozilla lists (text only), Rogue Amoeba tiles; keep — card surface, 18px radius.
- **Made ours:** every reference is a text list; none uses icons + dates, so this tile is the site's own. Shared core: one link per policy.
- **Rounds:** 1 built; 2 none; 3 dates kept on one line with non-breaking spaces (wrapped "3 August / 2026" at 390).
- **After (1440):** band 283px tall (was 410); 3 tiles in 1 row, 400×80 each (cards were 416×96 in 2 rows); date in 13px sans, tabular.
- **2-second test:** passes.

### 4. Supported products — support · new

- **Bar:** a visitor looking for their app finds 3 underlined words.
- **Brief:** weak — bare links; premium — icon tiles; refs — Rogue Amoeba support tiles, Panic help sections; keep — the same tile as part 3.
- **Made ours:** Rogue Amoeba shows icon + name only; here each tile also says what it is and where it runs, with an arrow. Shared core: one entry per product.
- **Rounds:** 1 built; 2–3 none needed.
- **After (1440):** 3 tiles 400×80 (links were 91×34); band 259px (was 214). (390): 427px (was 190).
- **2-second test:** passes.

### 5. Common questions — Magic Notes, Sole Focus · new

- **Bar:** questions buried as bold run-ins; you read every paragraph to find yours.
- **Brief:** weak — inline; premium — scannable Q&A; refs — Flighty open list, NN/g FAQ guidance; keep — prose column, hairline.
- **Made ours:** Sindre Sorhus uses grouped `<details>`; this keeps every answer open, ruled, with the question as a 20px heading. Shared core: question and answer.
- **Rounds:** 1 built; 2–3 none needed. CSS only, keyed to `#common-questions`; no content file changes.
- **After:** question 20px/650 on its own line; pairs ruled 1px; closing line 15px faint. Prose block 2023px tall at 1440 (was 1816).
- **2-second test:** passes (structure visibly changes), the weakest of the 5.
