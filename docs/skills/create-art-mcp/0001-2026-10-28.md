# Studio cover — run report

## What was bought

- Provider fal, Balanced tier: 3 probe sheets (A–H glow, I–P maker hint, Q–X magazine), all rejected by the owner as template-like and unrelated to the work.
- Spend: priced against about $0.24 for the 3 sheets. That figure was taken before the chat was summarised and was not measured again afterwards.
- Nothing else was generated. The cover was built by hand from the studio's own assets: the gem SVG, 3 tiles drawn for it as SVG, and real Waypost Words screenshots.

## How the design was picked

- Front: gem + "MetKap Studio" + "Small studio. Serious craft." ("craft." in the site orange), then 3 tiles for games, apps and websites.
- Background: 21 options over 3 rounds. The small-tile walls read as crowded. Option 21 won: tall phone screens tilted 9 degrees.
- Screens with a yellow board (ww05) or a big caption (ww03, ww07) were removed. Dune Reach sits low so its gold button falls off the edge.
- Owner's rule at delivery: text and tiles are placed separately. The gem and name hold the far left of each platform's visible area. The tiles stand over the screenshots at 73.5% across.

## What was proved

- `build/prove.py` measured all 12 files, and all 12 pass: exact size, RGB with no alpha, under every file limit a source gave, and the front inside the safe box.
- The check was first seen failing 3 times. Once on a website limit set without a source, which was removed. Once on a gem that rounded 1 px past Facebook's safe edge, which now rounds up. Once on tiles that ended half a pixel past it, which now round down.
- Sizes were read this run. Official sources: Google Play, Mastodon, LinkedIn and GitHub, plus Discord as quoted by search. The rest came from third-party guides. LinkedIn's own page now says 1512 x 256, not the 4200 x 700 that older guides give.
- Each layout was looked at with its safe box drawn, then all 12 together (`all-sizes.png`).
- Last look: no logo, watermark or stray text. Nothing in it could be taken for a rival's art. The only app shown is the studio's own Waypost Words.
- The site's `public/og-image.png` is now the website file, byte for byte. `npm run headless` ran on the card.

## What is not proved

- Nothing was uploaded, so no platform's real crop was seen.
- The safe boxes for YouTube, Facebook, X, Bluesky, Twitch and Reddit come from third-party guides.
- No share previews were refreshed, so the new link preview is only proven in `dist/`.

## What the provider file got wrong

- Nothing new about fal. One tool note: `probe-spread.py` failed all 3 full-bleed dark sheets, which were then judged by eye.
- A Nano Banana Pro job from the earlier icon run (01a181d6-9b56-7fa0-8a39-97f5d465a10b) was never collected. It is not part of this run.
