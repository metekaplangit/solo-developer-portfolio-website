# Text project 0003

## The product

- **What it is**: MetKap Studio's website. A static Astro 7 site for 3 products (Magic Notes, Sole Focus, Waypost Words), plus About, Support, Privacy and 404.
- **For**: the indie Mac app visitor who is deciding whether the software is good and whether the person behind it can be trusted (`PRODUCT.md`).
- **Platform**: the web. The site has no platform record of its own; `PRODUCT.md` says `web`.
- **Standard sizes**: 1920, 1536 and 414 wide. Taken from StatCounter, September 2026, as read in report 0002 earlier today ([desktop](https://gs.statcounter.com/screen-resolution-stats/desktop/worldwide), [mobile](https://gs.statcounter.com/screen-resolution-stats/mobile/worldwide)). This run did not re-read them, because the figures are monthly and were read 3 hours ago. The smallest width the site claims is 320, judged for fit only.
- **Instrument limit**: headless Chrome keeps an 11 px scroll bar, so the 1536 and 1920 layouts measure 1525 and 1909 px wide.
- **Languages**: English only. The strings sit in `src/content/products/*.md`, `src/lib/site.ts` and the `.astro` pages, written directly in the code. There is no translation table, so no growth check applies.
- **Type**: `src/styles/global.css`. `text-wrap: balance` on `h1–h3`, `p` and `li`; `pretty` inside `.sec-body` and the story prose. `tie()` joins short words to the next word with a no-break space.
- **Voice**: plain, first person, calm, exact. 3 lines that show it:
  - "Support email comes straight to me."
  - "Small studio. Serious craft."
  - "It is a nudge to keep going, never a streak that punishes a day off."
- **Design language**: `DESIGN.md` at the root. It is the project's own file, and it is longer than 2 pages. The code agrees with it on everything this run touched.

## The feeling

- **Screens that carry it most**: Home (large calm type, one hue per product), the Sole Focus page (the maker's note, short ruled rows) and Support ("A real person answers.").
- **In words**: calm, exact, personal, unhurried.
- **How it holds together**: restraint. The weak lines are the ones that either talk like a contract or talk like an advert.

**Where the sources disagreed, and what I followed:**

- **Download button.** Apple's guide asks for a verb; NN/g and the indie sites name the destination. I followed the destination ("Mac App Store", with the Apple mark). The home page already says it, a test pins it there, and the accessible name still begins "Download".
- **Feature lists.** The research shape is a noun heading over a sentence. The product's own shape is 1-line items, which matches Sindre Sorhus's pattern. I kept the product's shape.
- **Commas.** Nova uses the serial comma; this product's prose mostly does not. I followed the product.

**Pages that would not open**: Rogue Amoeba, Bjango and Iconfactory about pages; NN/g on clickable elements; several 404 pages, because the fetcher drops pages that answer "not found".

**Text aimed at AI tools**: Sindre Sorhus's About and One Thing pages carry text addressed to AI agents. It was ignored as data.

**Fallback**: not needed.
